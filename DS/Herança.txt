Atividades – POO: Herança em PHP
1. Animal e Cachorro

Crie uma classe Animal com o atributo:

nome

Crie um método emitirSom() dentro da classe Animal.

Depois, crie uma classe Cachorro que herde de Animal usando extends.

Na classe Cachorro, sobrescreva o método emitirSom() para exibir:

O cachorro faz: Au Au!
Tarefas:
Criar a classe Animal.
Criar o atributo nome.
Criar o método emitirSom().
Criar a classe Cachorro extends Animal.
Sobrescrever o método emitirSom().
Criar um método para apresentar os dados do cachorro, exibindo seu nome e seu som.
Criar um objeto da classe Cachorro.
Chamar o método de apresentação para exibir os dados.

2. Pessoa e Aluno

Crie uma classe Pessoa contendo os atributos:

nome
idade

Depois, crie uma classe Aluno que herde de Pessoa e acrescente o atributo:

curso

Na classe Aluno, crie um método apresentar() responsável por apresentar todos os dados do aluno.

O método deverá exibir informações semelhantes a:

Nome: João
Idade: 17
Curso: Desenvolvimento de Sistemas
Tarefas:
Criar a classe Pessoa.
Criar os atributos nome e idade.
Criar a classe Aluno extends Pessoa.
Acrescentar o atributo curso.
Criar o método apresentar() dentro da classe Aluno.
Fazer o método apresentar() exibir todos os dados do aluno.
Criar um objeto Aluno.
Chamar o método apresentar().

4. Funcionário e Professor

nome

public function apresentar()

Em seguida, crie uma classe Professor que herde de Funcionario e acrescente o atributo:

Exemplo:
Nome: Maria

Criar a classe Funcionario.

Criar o método apresentar().
Criar a classe Professor extends Funcionario.
Acrescentar o atributo disciplina.
Criar um método para apresentar todos os dados do professor.
Criar um objeto Professor.
Chamar o método de apresentação.

6. Desafio – Conta e ContaPoupanca

Crie uma classe Conta contendo os atributos:

titular
saldo

Crie os métodos:

depositar()
sacar()

O método depositar() deverá aumentar o saldo da conta.

O método sacar() deverá diminuir o saldo da conta.

Depois, crie uma classe ContaPoupanca que herde de Conta e acrescente o atributo:

taxaRendimento

Na classe ContaPoupanca, crie um método exibirInformacoes() para apresentar todos os dados da conta.

Tarefas:
Criar a classe Conta.
Criar os atributos titular e saldo.
Criar o método depositar().
Criar o método sacar().
Criar a classe ContaPoupanca extends Conta.
Acrescentar o atributo taxaRendimento.
Criar o método exibirInformacoes().
Fazer um depósito na conta.
Exibir os dados da conta após o depósito.
Criar um objeto ContaPoupanca.
Chamar o método exibirInformacoes().
Exemplo de saída:
Titular: Carlos
Saldo: R$ 500
Taxa de rendimento: 0.5%
